# 更新记录

## 0.2.0 · 2026-10-26

- 浮窗的「发送」直接提交到绑定的 Harness 原会话，沿用其模型、账号与上下文，不修改主窗口的草稿和附件。
- 截图问题改为选填；只发送截图时默认提问「请分析这张截图。」。支持纯文字追问，拒绝空内容。
- 增加最近 20 条用户/助手消息和实时回复显示，可选中文字复制，保留换行和代码原文；增加停止生成。
- 绑定会话独立于主窗口当前选择。主窗口切换或最小化后继续同步，点击其他会话的「截图提问」可明确重新绑定。
- 发送后保持浮窗显示。Esc、关闭按钮与快捷键隐藏窗口，重开保留输入和回答。
- 区分发送中、接收确认、排队、生成、完成和失败；成功确认后清空本次输入，失败或结果不确定时保留，断线不自动重发。
- 增加回复分块与最终消息去重；插件停用时释放订阅并退出本地组件。

验证：35 项 Node 测试、7 项原生自检及本地窗口测试通过。当前只交付源码和本地安装包，未替换正在使用的 Harness 插件；真实模型联调尚未完成，详见 [验证记录](VALIDATION.md)。

本期仅覆盖 Windows Harness；复杂 Markdown、工具卡片、ChatGPT 适配和后续草图的视觉调整尚未加入。
