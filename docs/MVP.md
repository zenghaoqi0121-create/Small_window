# 拾窗 MVP

目标宿主：Windows DeepSeek Harness 0.2.1-rc.2。先做可安装的本地 Harness 插件，包含 Skill 和受插件管理的 Windows 小窗组件。

链路：选中已有会话 → Alt+Space → 小窗输入问题与区域截图 → 放入该会话的原生草稿 → 用户在 Harness 发送，沿用该会话的模型与账号。首版回复在原会话显示，小窗不渲染回复。ChatGPT 适配、OCR、标注、语音与历史管理留到后续。

小窗：浅色背景、深灰文字、蓝色主按钮，微软雅黑；单一截图预览、问题输入框、当前目标会话提示。Esc 隐藏并保留草稿；截图 Esc 取消并保留上一张截图；Ctrl+Enter 放入会话。快捷键冲突时降级 Ctrl+Alt+Space 并显示实际快捷键。

接口边界：

- Skill 只提供读图指令，不宣称 Markdown 能注册系统快捷键。
- Host 插件启动一个 C# WinForms 组件，使用 stdin/stdout JSONL，不另开模型接口。
- Client 通过官方 conversation slot、createDrafts 与 inputActions 接入附件与文字。
- REST 由 Harness 的 requestRejection 验证，再限制回环来源与写请求来源。无认证能力时拒绝访问。
- 打开小窗时固定目标会话；目标切换后等待回到原会话，不把图片重定向到新会话。仅原始客户端可领取。
- 图片仅短期驻留内存，不记录截图正文与用户问题；客户端确认接收后清理，未接收内容十分钟过期。
- 不修改安装包、账号、模型设置与现有用户会话。

验证：Node 单元测试（路由、队列、会话隔离、失败与重试）；C# 编译及自检（选区坐标、PNG 编码）；客户端接口契约检查；可安装包检查。实际宿主安装及截图交互另记录实测结果，不用模拟测试冒充端到端通过。
